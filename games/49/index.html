ABCnagrams

In this puzzle, you're given 26 scrambled clues, each representing a JS term with one missing letter. Your task is to figure out the missing letter, add it back, and unscramble the result to reveal the correct JS term. All missing letters are unique and don't repeat. The words and letters are not in alphabetical order. Some of the JS terms are deprecated, some others are experimental. Or maybe not... :)

If you get stuck, you can refer to the hints and solution page for assistance. (It has links to all the terms if you want to learn more about them.)
